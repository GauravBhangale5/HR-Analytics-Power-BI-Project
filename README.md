# 📊 HR Analytics - Power BI Project

## 📌 Overview
This project presents an **HR Analytics Dashboard** built using **Power BI** to analyze key HR metrics, employee performance, and workforce trends. The dashboard provides valuable insights to help HR teams make data-driven decisions regarding employee retention, performance evaluation, and workforce planning.

## 🎯 Key Features
✅ **Employee Performance Analysis** - Track employee KPIs & efficiency 📈  
✅ **Attrition & Retention Trends** - Identify turnover patterns & retention factors 🔄  
✅ **Department-Wise Insights** - Analyze workforce distribution across departments 🏢  
✅ **Diversity & Inclusion Metrics** - Gain insights into workforce demographics 👥  
✅ **Interactive Visualizations** - Dynamic filters for custom analysis 🔍  

## 🛠️ Technologies Used
- **Power BI** - Data visualization & analytics 📊
- **Excel / CSV** - Data source for HR insights 📄

## 📂 Installation & Usage
1. **Download the .pbix File** ➡️ [Click Here](https://github.com/GauravBhangale5/HR-Analytics-Power-BI-Project/blob/main/HumanResources.pbix)  
2. **Open with Power BI Desktop** 🏗️  
3. **Explore the Dashboard** - Use filters & charts to analyze HR trends 🔎  

## 📊 Dataset Overview
The dataset includes:
- 👤 **Employee Details** - Name, age, department, role, and experience
- 💼 **Performance Metrics** - Productivity, efficiency, and KPIs
- 📉 **Attrition Factors** - Resignation trends and influencing factors
- 📊 **Workforce Demographics** - Age, gender, and diversity metrics

✔️ Tracking performance trends across departments  
✔️ Understanding workforce demographics for HR planning
